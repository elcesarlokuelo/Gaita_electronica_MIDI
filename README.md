# Gaita electrónica MIDI  
Este ha sido mi trabajo de Fin de Grado en el Grado en Ingeniería Electrónica, Robótica y Mecatrónica. Consiste en el diseño de una gaita electrónica MIDI.  
 Todo el contenido de trabajo está subido a este repositorio.  
 Organización del repositorio:  
 -Archivos .STL: Conjunto de los modelos 3d de las piezas diseñadas.  
 -Archivos .gcode: Archivos para la impresión 3d.  
 -Archivos .FCStd: Modelos 3d en el formato de FreeCAD.  
 -Presets del sintetizador: archivos con los presets del sintetizador que he utilizado. En este caso Universal Piper.  
 -version_final_gaita: Archivo .ino para el microcontrolador Arduino UNO utilizado.  
 -TFG Gaita.pdf: PDF con toda la información y la memoria del TFG.  
 -gaita_esquemático.png: planos de las conexiones electrónicas. Realizado con Fritzing.  
 -planos.pdf: Planos de las piezas de la gaita.
